# Проект "PyFlyPro2"
## Описание: 
Проект "PyFlyPro2" - это Консольное приложение для поиска и фильтрации 
самолётов по данным OpenSky Network.

## Установка
1. Клонируйте репозиторий:
``` git clone https://github.com/211krasnaya-sudo/project6.git
```

## Установите зависимости:
```poetry install```
```pip install -r requirements.txt```

## Запуск

```bash
poetry install
poetry run python src/main.py
```
## Принципы SOLID в реализации
1. Каждый модуль отвечает за одну зону ответственности (API, хранение, утилиты, CLI).
2. Базовый класс BaseSaver позволяет добавлять новые типы хранилищ без изменения существующего кода.
3. JSONSaver корректно реализует интерфейс BaseSaver.
4. Интерфейсы минимальны и ориентированы на конкретного потребителя.
5. Зависимости от API и хранилищ вынесены в абстракции, а не в детали реализации.

## Особенности и ограничения
1. Для работы требуется доступ в интернет (запросы к OpenSky и Nominatim).
2. Данные кэшируются в JSON-файле (путь задаётся константой DATA_FILE).
3. Проект учебный.

## Функционал:
- Искать самолёты по стране (через Nominatim).
- Фильтровать по высоте и выводить топ‑N по высоте.
- Сохранять результаты в JSON.
- Валидировать ввод пользователя и обрабатывать ошибки.


Пример использования:
```text
Введите страну (например, Spain): Spain
Выберите действие:
1 - Топ N самолётов по высоте полёта
2 - Самолёты по стране регистрации
3 - Фильтр по диапазону высот
0 - Выход
> 1
Введите N: 3
Найдено самолётов: 2
1. BBB (высота: 9000 м)
2. AAA (высота: 5000 м)
```
